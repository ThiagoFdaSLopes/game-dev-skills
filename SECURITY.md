# Security policy

These skills are instructions for coding agents; they ship no executable code to users. A security issue here is a skill text that could lead an agent to do something harmful or unauthorised: run destructive commands, leak secrets, publish or push without the user's consent, or follow instructions injected through files it reads.

## Reporting

Please report it privately through GitHub's **private vulnerability reporting**: the "Security" tab of this repository, then "Report a vulnerability". Do not open a public issue.

Include the skill, the agent and model, the prompt or file that triggered the behaviour, and what the agent did. You will get an answer as soon as possible; fixes ship in a patch release with credit to the reporter unless you prefer otherwise.

## Supported versions

Only the latest release is supported.

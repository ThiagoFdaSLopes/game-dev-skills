# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what is best for the community. Harassment, insults, personal or political attacks, sexualized language or imagery, and publishing others' private information are not acceptable, in the repository or in any space that represents the project.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@ThiagoFdaSLopes](https://github.com/ThiagoFdaSLopes), through a private message on GitHub, or by opening a minimal issue that asks for a private contact (no details in public). Reports are handled confidentially.

The maintainer may remove, edit or reject comments, commits, issues and pull requests that break this code, and may ban contributors temporarily or permanently, following the enforcement guidelines of the Contributor Covenant 2.1.
